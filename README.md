# Slotify API

Slotify is a backend booking API built with Node.js, Express, MongoDB, and JWT authentication.

It allows users to register, log in, view slots, book available slots, cancel their own bookings, and view their active bookings.

## Features

- User registration and login
- JWT authentication
- Password hashing with bcryptjs
- Create, read, update, and delete slots
- Book available slots
- Cancel bookings
- Booking ownership checks
- Prevent double booking
- Filter available slots
- Detect overlapping time conflicts
- View bookings for the logged-in user
- MongoDB Atlas persistence
- Deployed publicly on Render

## Tech Stack

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JSON Web Token
- bcryptjs
- dotenv
- Render
